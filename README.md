🎓 ỨNG DỤNG TƯƠNG TÁC VÀ HỖ TRỢ HỌC NHÓMMột ứng dụng di động đa nền tảng được thiết kế nhằm giúp sinh viên dễ dàng trao đổi, theo dõi tiến độ và phối hợp học tập hiệu quả hơn. Đặc biệt phù hợp cho các hoạt động làm việc nhóm, quản lý dự án học tập và tương tác trực tuyến.
🛠️ Công nghệ sử dụngFrontend: 
React Native (Phát triển ứng dụng đa nền tảng Android/iOS).
Cơ sở dữ liệu: Hệ sinh thái Firebase, cloudinary, supabase.
Backend/Services: Server Node.js (Hỗ trợ thông báo đẩy).
